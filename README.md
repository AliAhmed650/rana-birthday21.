# موقع عيد ميلاد 🎂

موقع ثابت (HTML/CSS/JS) من غير أي تثبيتات.

## الإعداد
1. افتح `config.js` وغيّر الأسماء (`herName` و `hisName`).
2. حط الصور في `assets/photos/` والفيديوهات في `assets/videos/`، وسجّلها في `config.js` جوه `photos` و `videos`.
3. افتح `index.html` في المتصفح للتجربة.

## النشر على GitHub Pages
1. اعمل Repository جديد على GitHub وارفع محتوى الفولدر ده.
2. من **Settings → Pages** اختار Branch: `main` و Folder: `/ (root)`.
3. بعد دقيقة هتلاقي الرابط جاهز تبعته لها.

> نصيحة: الفيديوهات الكبيرة (أكتر من 100MB للملف) مش بتترفع على GitHub العادي، صغّرها الأول أو استخدم صيغة MP4 مضغوطة.
